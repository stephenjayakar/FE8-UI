# FE8 Extended Frontend 0.2.0

This beta release adds Windows x64 support alongside macOS and Linux.

## Changes

- Add a portable Windows executable with statically linked SDL2, FreeType,
  zlib, and the Visual C++ runtime.
- Add a PowerShell build script and Windows CI, including the full unit-test
  suite and command-line startup check.
- Build Windows releases from a Mac through GitHub Actions, with no local
  Windows toolchain required.
- Fix static mGBA compile definitions for consumers, use C11 for the tests,
  and make large test fixtures work with Windows' default stack size.

## Downloads

- **Windows x64:** Extract the ZIP. From PowerShell in the extracted directory,
  run `./bin/fe8-mgba-sdl.exe --rom 'C:/Games/fireemblem8.gba'`.
  Add `--save 'C:/Games/fireemblem8.sav'` and
  `--quick-state 'C:/Games/fireemblem8.ss'` for explicit save paths.
- **macOS arm64:** Apple Silicon application with its SDL runtime bundled.
  Extract the ZIP and move the app to Applications. Ad-hoc signed, not notarized.
- **Linux x86-64:** Built on Ubuntu 24.04. Install runtime dependencies with
  `sudo apt install libsdl2-2.0-0 libfreetype6 fonts-dejavu-core zlib1g`, then
  run `./fe8-mgba-sdl --rom /path/to/game.gba` from a graphical desktop.
- **Source with mGBA:** Includes the pinned emulator source and the frontend's
  build-time compatibility fix. Upstream cinema test fixtures are omitted.
- **SHA256SUMS.txt:** SHA-256 checksums for the four downloads.

## Scope

Windows uses the SDL game window and desktop Armory. The native game library,
settings menus, and OpenGL shader presets remain macOS-only. Extended rendering
and Armory support depend on the ROM profile. ROMs and save files are not included;
gameplay validation of the Windows build still requires a user-supplied ROM.

mGBA is pinned to `afd6f14eaf8bd35214ed3fb9dc69a92bfc3877a9`.
