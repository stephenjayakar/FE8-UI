# 0.2.1

## Windows desktop support

- Double-clicking the executable now opens a persistent ROM library with Add
  ROM, Play, Resume State, Remove entry, and Save folder controls.
- Games have native File, State, Settings, Armory, and Help menus. Settings
  include audio, VSync, extended rendering, mouse controls, fast-forward speed,
  zoom sensitivity, and keyboard/hotkey bindings.
- Library launches automatically configure isolated cartridge saves and quick
  states by ROM SHA-1. Existing sibling cartridge saves are imported once.
- Startup failures show an error with a log location instead of disappearing.
- Command-line launch remains supported. CRT shaders remain macOS-only.

Extract the Windows ZIP and open `bin/fe8-mgba-sdl.exe`. Add your own `.gba` ROM
and choose Play. Use State > Quick save before trying Resume State.

## Validation

Windows tests cover Unicode ROM paths, stable per-ROM save locations, and CLI
dispatch. A hidden-window regression test checks library import/persistence,
reference-only removal, native menu contents, settings persistence, and save/load
callback dispatch without showing windows or sending desktop input.

No ROMs or game assets are included.
